# 그리드 UI/UX 기본 원칙

## 1. 레이아웃 & 구조

### 1-1. 컴포넌트 구조
```
.component
  ├─ .title
  │   ├─ <h4> 제목 + 총 건수
  │   └─ <div> 버튼 그룹
  └─ .grid
      └─ <Tabulator>
```

**원칙:**
- 모든 그리드는 `.component > .grid` 구조로 감싸기
- 제목은 `<h4>` 태그 사용
- 버튼은 우측 정렬

### 1-2. 컬럼 너비
```javascript
- 순번(No.): 60px
- ID/코드: 100-120px
- 이름/명칭: 150-200px
- 설명: 200-500px
- 날짜/시간: 120-160px
- 금액: 100-150px (우측 정렬)
- 상태/여부: 80-100px (중앙 정렬)
```

**원칙:**
- 중요 컬럼(ID, 이름)은 고정 너비
- 부가 정보는 가변 너비
- 전체 너비가 화면을 초과하면 `layout="fitDataFill"` 대신 가로 스크롤

### 1-3. 높이 설정
```scss
.component {
  height: auto;  // 기본
}

.h300 { height: 300px; }  // 작은 그리드
.h500 { height: 500px; }  // 중간 그리드
.h700 { height: 700px; }  // 큰 그리드
```

**원칙:**
- 데이터 양에 따라 적절한 높이 설정
- 스크롤이 필요한 경우 명시적으로 높이 지정
- 2개 이상 그리드는 높이 분배 고려


## 2. 데이터 표시

### 2-1. 정렬 (hozAlign)
```javascript
- 좌측 정렬: 텍스트, 이름, 설명
- 중앙 정렬: 코드, 상태, 여부, 체크박스
- 우측 정렬: 숫자, 금액, 수량
```

### 2-2. 포맷팅
```javascript
// 날짜
formatter: 'dateTime'  // YYYY-MM-DD HH:mm:ss
formatter: 'date'      // YYYY-MM-DD

// 숫자
formatter: 'number'    // 천단위 구분
formatter: 'currency'  // 금액 (원)

// 체크박스
formatter: 'checkbox'
formatterParams: { check: 'Y', uncheck: 'N' }

// 상태
formatter: function(cell) {
  const value = cell.getValue()
  return value === 'Y' ? '사용' : '미사용'
}
```

**원칙:**
- 데이터 타입에 맞는 포맷터 사용
- 일관된 날짜/시간 형식
- 금액은 항상 천단위 구분

### 2-3. 순번(No.) 표시
```javascript
{
  title: 'No.',
  field: 'no',
  formatter: 'rownum',  // 또는 ROW_NUMBER() OVER ()
  width: 60,
  hozAlign: 'center',
  download: false  // 엑셀 다운로드 제외
}
```


## 3. 상호작용 (Interaction)

### 3-1. 편집 가능 여부
```javascript
// 전체 컬럼 편집 가능
editor: 'input'

// 조건부 편집
editable(cell) {
  return cell.getData().status === 'C'  // 신규만
}

// 편집 불가
editor: false  // 또는 속성 생략
```

**원칙:**
- PK 컬럼은 신규(status='C')에서만 편집 가능
- 시스템 생성 컬럼(등록일시, 수정일시 등)은 편집 불가
- 읽기 전용 데이터는 명시적으로 `editor: false`

### 3-2. 행 선택
```javascript
{
  title: '선택',
  formatter: 'rowSelection',
  titleFormatter: 'rowSelection',  // 전체 선택
  headerSort: false,
  width: 60,
  hozAlign: 'center',
  download: false
}
```

**원칙:**
- 삭제/수정 기능이 있으면 선택 컬럼 필수
- 전체 선택 기능 제공
- 선택된 행은 시각적으로 강조

### 3-3. 버튼 배치
```
좌측: 데이터 조작 (신규, 삭제, 복사 등)
우측: 조회/저장 (초기화, 조회)
우측 끝: 강조 버튼 (조회 - btn-gray)
```

**버튼 순서:**
1. 신규
2. 삭제
3. 저장
4. 초기화
5. 조회 (강조)


## 4. 상태 관리

### 4-1. 행 상태 (status)
```javascript
'R': Read (조회된 데이터, 변경 없음)
'C': Create (신규 추가)
'U': Update (수정됨)
'D': Delete (삭제 예정)
```

**원칙:**
- 모든 행은 status 필드 필수
- 저장 시 status !== 'R' 인 것만 전송
- status는 화면에 표시하지 않음 (visible: false)

### 4-2. 상태별 스타일링
```javascript
rowFormatter(row) {
  const status = row.getData().status
  if (status === 'C') {
    row.getElement().style.backgroundColor = '#e8f5e9'  // 신규: 연한 녹색
  } else if (status === 'U') {
    row.getElement().style.backgroundColor = '#fff3e0'  // 수정: 연한 주황
  } else if (status === 'D') {
    row.getElement().style.backgroundColor = '#ffebee'  // 삭제: 연한 빨강
  }
}
```


## 5. 사용자 피드백

### 5-1. 로딩 상태
```javascript
// 조회 중
if (isLoading) return <Loading />

// 데이터 없음
if (list.length === 0) {
  return <div className="no-data">조회된 데이터가 없습니다.</div>
}
```

### 5-2. 검증 메시지
```javascript
// 필수값 검증
if (!row.brandId) {
  alert(`브랜드 ID는 필수입력 항목입니다.[${i + 1}행]`)
  return
}

// 저장 데이터 없음
if (changed.length === 0) {
  alert('저장할 데이터가 없습니다.')
  return
}
```

### 5-3. 성공/실패 메시지
```javascript
// 성공
alert(getMessage('common_msg_001', { status: '저장' }), {
  okCallBack() {
    setSearchParams({ coId, userid })  // 재조회
  }
})

// 실패
alert('저장 중 오류가 발생했습니다.')
```



## 7. 접근성 (Accessibility)

### 7-1. 키보드 네비게이션
- Tab: 다음 셀 이동
- Shift+Tab: 이전 셀 이동
- Enter: 편집 모드 진입/저장
- Esc: 편집 취소

### 7-2. 스크린 리더
```javascript
// 컬럼에 의미 있는 title 제공
{ title: '브랜드 ID', field: 'brandId' }

// 버튼에 aria-label
<button aria-label="신규 브랜드 추가">신규</button>
```


## 8. 일관성 원칙

### 8-1. 명명 규칙
```javascript
// 카멜케이스 (JavaScript/React)
brandId, brandNameKo, useYn

// 스네이크케이스 (Database)
BRAND_ID, BRAND_NAME_KO, USE_YN

// 케밥케이스 (CSS)
.btn-gray, .outline-button
```

### 8-2. 공통 컬럼
```
모든 테이블 기본:
- CO_ID (회사코드)
- USE_YN (사용여부)
- REG_DTTM (등록일시)
- REGR_ID (등록자ID)
- UPDT_DTTM (수정일시)
- UPDT_ID (수정자ID)
```

### 8-3. 버튼 스타일
```scss
.btn                 // 기본 버튼
.btn.outline-button  // 아웃라인 버튼 (신규, 삭제, 저장, 초기화)
.btn.btn-gray        // 강조 버튼 (조회)
```

## 10. 실전 예제

### 기본 CRUD 그리드
```jsx
<div className='component'>
  <div className='title'>
    <h4>브랜드 관리</h4>
    <div>
      <button className='btn outline-button' onClick={handleAdd}>신규</button>
      <button className='btn outline-button' onClick={handleDelete}>삭제</button>
      <button className='btn outline-button' onClick={handleSave}>저장</button>
      <button className='btn outline-button' onClick={handleReset}>초기화</button>
      <button className='btn btn-gray' onClick={handleSearch}>조회</button>
    </div>
  </div>
  <div className='grid'>
    <SimpleTabulator
      ref={gridRef}
      data={list}
      columns={columns}
      layout="fitColumns"
    />
  </div>
</div>
```
